Mock exam one, part two.

Question 1.
Topic: cd-agents
A team must choose an architecture for four workloads. Which two need an agent loop rather than a predefined workflow? Choose two.
A. Translating each product page into five languages, using an approved glossary for terms
B. Converting supplier CSV files into a fixed JSON format, with validation of every field
C. Investigating why a nightly job fails, with no known cause
D. Researching vendors, following leads as they appear
E. Classifying incoming emails into four categories
[THINK]
The answers are C and D. Their steps depend on what's found along the way. The others are fixed, predictable pipelines that a workflow handles more cheaply and reliably.

Question 2.
Topic: cd-agents
A team wrote its own agent loop on the Messages API. It now needs file and shell tools, permission controls, resumable sessions and subagents. What's the most effective next step?
A. Add an MCP server for each missing capability
B. Adopt a graph orchestration framework
C. Write the missing features into the custom loop one by one, reusing the existing code
D. Adopt the Claude Agent SDK, which provides file and shell tools, permissions, sessions and subagents out of the box

The answer is D. The Agent SDK is Claude Code's agent harness as a library. MCP adds tools but not the harness.

Question 4.
Topic: cd-agents
A coding agent sometimes declares a task complete without running the tests, despite a system prompt instruction to always run them. What gives a guarantee?
A. Repeat the instruction at the end of every user message, so it's always the most recent text
B. Raise the effort level to maximum
C. A hook on the stop event that blocks the agent from completing until the full test suite has run and passed
D. A larger model that follows instructions better, combined with a reminder in every user message
[THINK]
The answer is C. A hook runs deterministically. Instructions, effort and model size remain probabilistic.

Question 5.
Topic: cd-agents
An orchestrator delegates code searches to subagents. The subagents often fail because they don't know which service the user is working on. What's the likely cause?
A. Subagents can't use search tools
B. Subagents need the most capable model to infer the missing context on their own
C. The task messages to the subagents weren't self-contained
D. The orchestrator used too many subagents at once, so they lost track of the shared conversation
[THINK]
The answer is C. A subagent starts with a fresh context, so the task message must include the context it needs.

Question 11.
Topic: cd-code
A team's Claude Code pre tool use hook, which blocks writes to the migrations folder, is defined in one developer's settings dot local dot json. Other developers' sessions don't enforce it. What should they do?
A. Copy the rule into CLAUDE dot M D
B. Ask each developer to install the hook manually in their own user settings file
C. Move the hook to the committed dot claude slash settings dot json, or to managed settings for the whole organization
D. Enforce it only in CI
[THINK]
The answer is C. The local settings file is personal and not committed. CLAUDE dot M D is guidance, not enforcement, and CI doesn't cover local sessions.

Question 12.
Topic: cd-code
A security hook detects a forbidden command and exits with status one, but the command still runs. Why?
A. Hooks can't block bash commands
B. Only exit code two blocks the action
C. The hook must print the word deny on standard output, in addition to the exit status
D. The hook needs to run after the tool, not before

The answer is B. Exit two blocks and passes the error output to Claude as the reason. Alternatively, return JSON with a deny decision.

Question 18.

Which two practices are correct for API keys? Choose two.

B. An admin key in the application, for full access
E. One shared key for all teams, to simplify billing
D. Keys embedded in the mobile app, so calls skip a network hop and respond faster

Question 25.
Topic: cd-eval
