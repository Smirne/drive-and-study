Question 1.
Topic: cd-agents
A team must route support requests: password resets go to an automated script, billing questions to a finance prompt, and everything else to a general assistant. Which pattern fits?
A. Orchestrator-workers
B. Evaluator-optimizer
C. Voting
D. Routing
[THINK]
The answer is D. Classification followed by a specialized path is routing.

Question 2.
Topic: cd-agents
A legal team wants contract summaries that must meet a checklist of twelve criteria. Drafts often miss one or two items. Which pattern fits best?
A. Evaluator-optimizer, where one call drafts, another checks against the criteria and gives feedback, until the draft passes
B. Routing
C. Sectioning
D. A single call at higher temperature
[THINK]
The answer is A. Clear evaluation criteria and measurable gains from iteration are the evaluator-optimizer's use case.

Question 3.
Topic: cd-agents
A content moderation pipeline must flag policy violations with high confidence. Which parallelization variant fits?
A. Sectioning, splitting the text into parts that are checked at the same time
B. Voting, running the same check several times or with several prompts, and combining the verdicts
C. Prompt chaining
D. Orchestrator-workers
[THINK]
The answer is B. Voting runs the same task multiple times for more confidence.

Question 4.
Topic: cd-agents
An orchestrator spawns subagents for tiny tasks, such as reading one small file, and the run becomes slower and more expensive. What does the guidance suggest?
A. Spawn more subagents in parallel
C. Give every subagent the most capable model, so each small task finishes in one step
B. Delegate only parallel or noisy work
D. Disable the main agent's tools, so all work goes through subagents consistently
[THINK]
The answer is C. Subagents add overhead. They pay off for isolation and parallelism, not for trivial steps.

Question 5.

B. The task messages didn't define each scope

The answer is D. Clear, self-contained task descriptions with explicit boundaries prevent duplicate work and gaps.

Question 7.

Question 8.
